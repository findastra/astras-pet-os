## Repository shape

Node.js with built-in modules only, plus Windows desktop programs in C# for .NET Framework 4
(built with the `csc.exe` that ships with Windows). There is no server, database, API, login or
package dependency.

## Findings that need Astra

1. **Visibility does not match what was intended.** `data-dealer` and `voicemeeter-bug` are
   public on GitHub but recorded as private; `rift-rabbit` is public but Astra listed it as
   private. `astras-pet-os` itself is public (its AGENTS.md now says so). Nothing was changed.
2. **Chip and CHIP.** v5.2 says Data Dragonfly works "alongside CHIP and Data Dealer without
   treating either project as a pet", but Chip is today the registered pet for `data-dealer`.
3. **Linux Penguin.** The only penguin in the repo is Portfolio Puffer, a portfolio pet. There
   is no existing Linux penguin, so Linux Penguin would be new and does not collide.
4. **Raspberry Pie vs `raspberry-berry` / "Raspberry Pi".** Three spellings for one pet.

## Versions today

No pet has a SemVer `version` in its registry entry. The hub's own `pet.json` has
`"version": "0.2.1-20261008"` (SemVer with a date as a pre-release tag), and some pets record
`source_tag` / `source_commit`. GitHub Goldfish compares registry text with each repo but does
not compare releases.
