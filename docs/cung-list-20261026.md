# The Cung List (2026-10-26)

Astra asked for "the Cung List": 15 ideas from [Tyson Cung's public GitHub](https://github.com/tysoncung), each fitted
to one of her own repos. Her rules for it: existing repos only, free tiers only (no paid kits), one branch and one pull
request per work item, and anything that has to run on her Windows PC ships as a script she runs once. Nothing here is
merged until Astra says so in chat.

The ideas are Tyson Cung's; where an idea is someone else's open-source tool that he uses or lists (Context7,
Superpowers, Serena, Ollama, n8n, ccusage, Gemini CLI, Dyad, Mem0, Zep), the tool's own makers are named in its row.

## Run once on the PC

When the PC is on, from a normal (not administrator) PowerShell window in the hub folder:

```
powershell -ExecutionPolicy Bypass -File scripts\cung-list-install-20261026.ps1 -DryRun
powershell -ExecutionPolicy Bypass -File scripts\cung-list-install-20261026.ps1
```

The first line only shows what it would do. Each step checks first and skips what is already there, so running it again
is safe. It ends with a table of every step.

| Step | What | How | Administrator? |
|---|---|---|---|
| 1 | Ollama | `winget install --id Ollama.Ollama --scope user` | No |
| 2 | Node.js LTS, only when `node` is missing | `winget install --id OpenJS.NodeJS.LTS` | Yes: Windows asks |
| 3 | uv (MCP for Unity's server runs on it, card 306; already on the PC since 2026-11-08) | `winget install --id astral-sh.uv` | No |
| 4 | Docker Desktop, only if she answers y | `winget install --id Docker.DockerDesktop --interactive` (its own installer window) | Yes: Windows asks |
| 5 | Gemini CLI | `npm install -g @google/gemini-cli` | No |
| 6 | Dyad | `winget install --id Dyad.Dyad --scope user`; if winget fails, the download page https://www.dyad.sh/ | No |
| 7 | ccusage, a test run only | `npx -y ccusage@latest daily --since <a week ago>` | No |

What the script never does: read, change or sign in with Astra's Claude account or its credentials; set an API key; add
anything to Startup apps (only Startup Star belongs there, AGENTS.md); run itself as administrator. Ollama's installer
adds itself to Startup apps on its own; the script says so, and she turns it off in Task Manager.

The winget package ids were checked against the winget catalog (microsoft/winget-pkgs) on 2026-10-26: `Ollama.Ollama`
(user install), `OpenJS.NodeJS.LTS` (installs for all users), `astral-sh.uv` (portable), `Docker.DockerDesktop` (all
users), `Dyad.Dyad` 1.19.0 (user install, Apache-2.0).

## Context7 and Serena (items 2 and 7): not adopted here

Astra, 2026-11-09 (hub card 319, the deck "MCP Server Questions", "All recommended"): keep Serena off, and take it and
the second Context7 out of this branch.

- **Context7** was already connected to Claude as a connector, so a project copy in `.mcp.json` would only have been a
  second door to the same server. Codex has no Context7; adding it there is a new decision for Astra.
- **Serena** (Oraios AI's open-source coding tool) gives an agent symbol-level edit tools and asks it to prefer them
  over its own. Claude Code's own search and edit tools already handle these repos, so it stays off. On 2026-10-26 this
  branch had it pinned to commit `9e1cced`, in its `ide` context, and it answered the MCP handshake with 23 tools; that
  record is in the branch history and in `docs/mcp-assessment-20261109.md`, row 29.
- So this branch has no `.mcp.json` and no `.serena/` folder, and the install script no longer fetches Serena. uv stays
  in the script because MCP for Unity's server runs on it (card 306).

## Superpowers (item 4)

The method (brainstorm, written plan, test first, build, self-review, verification) is now in the shared pet-app skill,
fitted to Astra's own steps: [skills/pet-app/SKILL.md](../skills/pet-app/SKILL.md), "Building a new pet". None of
Superpowers' files were copied in. The plugin itself is optional; it is third-party, community tier, MIT. In Claude Code:

```
/plugin install superpowers@claude-plugins-official
```

or, from its makers' own marketplace:

```
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace
```

In Codex: `/plugins`, search `superpowers`, Install Plugin. Its brainstorming page loads a logo that reports the
Superpowers version to its makers; `SUPERPOWERS_DISABLE_TELEMETRY=1` (a Windows user environment variable) turns that
off. Where it disagrees with the hub (it offers to merge locally, and names files date first), the pet-app skill says
which rule wins.
