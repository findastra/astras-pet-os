# Intelligence levels: what each intelligent app has built

2026-10-14, OpenAI Codex (GPT-6): shared authorization reference verifier and attack tests added
(`scripts/access-policy-20261014.mjs`, `test/access-policy-test-20261014.mjs`). This does not make any pet's
L3 harness operational. Intel Owl is planned seed #81; the complete catalog is [PET-PROGRAMS.md](PET-PROGRAMS.md).

Every intelligent app (a pet) grows through **three levels of intelligence**, as decided for
ASTRAS_PET_OS ([ASTRAS_PET_OS.md](ASTRAS_PET_OS.md), section 2) and drawn on the [System Map](system-map-20261012.html),
and answers to a fourth: **L4, the verified human who owns the entire secure ecosystem**.

**Written L1, L2, L3 and L4 from 2026-10-13; L1 and L2 redrawn on 2026-10-14 (Astra).** In the per-pet table below,
column 1 (the pet's own program) and column 2 (its runtime) together are L2 today, column 3 is L3, and the programs and
tools a pet runs (L1) are listed in its code and links.

| Level | Name | What it is | Map layer |
|---|---|---|---|
| L1 | **Programs** | The third-party programs it runs (SteamVR, Voicemeeter, Unity), plus the programs and tools it creates. | Rings 3 and 5 |
| L2 | **Pet program** | The pet's dashboard, and its runtime: it runs on its own without you opening it (scheduler, inbox, saved state, health), and keeps working when the Farm, the Farmer or Startup Star is closed. | Ring 3 |
| L3 | **Agentic harness** | An AI model sits in the pet program's harness and becomes its agent: model adapter (Claude, GPT or local), skills (tricks), tools, memory, permissions, task executor. Decides what to do next. | The harness and its seat |
| L4 | **Verified human** | The verified human who owns the entire secure ecosystem (on Astra's farm, Astra; on another user's farm, that user). Approves every security change, every permission and every exception to a default, such as an L3 agent running more often than weekly. Not something a pet builds: every pet answers to L4. | 1 You (ring 8) |

Every pet program is built to [PET-PROGRAM-FRAMEWORK.md](PET-PROGRAM-FRAMEWORK.md).

**Levels:** ✅ built and verified · 🟡 partly there (see note) · — not built.
**Program names:** each pet's program has a different name from the pet, so the two are easy to tell apart. *Italic* names are suggestions for Astra to approve; **bold** names are the program's real name today. **Made by Astra** programs are hers; **made by others** are other people's software the pet looks after (on the map: pink cubes and peach cubes, on separate shells).
**Runtime** says what the pet should do on its own (Astra's words, 2026-10-12) and what it does today. **Updates** says when it runs and what it updates: "Today" is real, "Suggested" is a proposal.

Not built yet is not an error. An error ($\color{red}{\textsf{red}}$) is something broken, missing from GitHub, or out of step:
🏷️ name mismatch · 🔌 PC folder not connected to its GitHub repo · 💻 only on the PC, not on GitHub ·
🚧 stuck in an unmerged pull request or on a branch · ⏰ scheduled task not installed · ❓ missing from the registry ·
🖼️ art missing or different · 📦 code in the wrong repo · 🧩 the program it looks after is not installed

**Kind:** registered (in the registry with art) · pipeline (on GitHub, no registered art) · seed (approved name, no repo) · unregistered.
