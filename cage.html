Get the Cage

  1. Look at it: open cage.html from this repo in any browser. It needs no install and no network.
  2. Take it with you: on the repo page press Code, Download ZIP, unzip, and double-click cage.html. Or git clone https://github.com/findastra/astras-pet-os.
  3. Get a pet: each pet is its own repo (see the table). Download its ZIP the same way. Pets not on GitHub yet say so.

The full instructions, the file rules for new pets and the running roster are in README.md, PET-FILES.md and ROSTER.md.
