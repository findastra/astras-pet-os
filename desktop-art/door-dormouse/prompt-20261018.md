# Door Dormouse draft artwork

By Astra. Prepared with OpenAI Codex (GPT-6), 2026-10-18.
Generated with the built-in image generation tool, no external reference artwork.
Original character: Door Dormouse, The Threshold's caretaker for Liminal Doors.
Draft until Astra approves the design. Nine transparent mood frames, 256 by 256 pixels.
The desktop host currently animates idle and blink only; all nine frames are supplied.
One source sheet in this folder; local installation caches byte-identical frames.

## Generation prompt

Use case: stylized-concept. Asset type: production transparent pixel-art desktop-pet 3-by-3 nine-mood sprite sheet for Astra's PetOS. Create Door Dormouse, an original sleepy tiny dormouse carrying ONE prismatic key, seated front-facing, round compact body, large round ears, small round paws, short curled fluffy tail visible at the side. A unique neon palette: luminous peach-apricot fur, ivory muzzle and belly, saturated midnight-indigo inner ears and tail tip, key with cyan/rose/lime glass facets. No other characters or scene props. Polished fine SNES pixel art, crisp hard pixel edges, flat solid colors with one shade, no gradients/dithering/3D/soft rendering. Every silhouette has a solid BLACK outline one sprite-pixel thick. Simple dark dot eyes with single white highlight, small pink blush cheeks and tiny w mouth. Exact evenly spaced 3x3 grid, wide transparent gutters, full body inside each cell, same size and centered position in every cell. ONLY facial expression changes; identical body pose, key and colors in all nine. Left to right top to bottom: calm neutral; blink eyes closed; happy; curious; worried; sad; unwell; shocked; asleep. Curious: symmetric identical eyes looking straight forward, raised brow and small open mouth. Genuine transparent alpha outside characters, no backdrop, glow, cast shadow, grid lines, labels, lettering, numbers. Do NOT draw mood symbols: no punctuation, question marks, exclamation marks, Z letters, tears, sweat drops or bandages; those are composited separately.
