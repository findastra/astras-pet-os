# astras-pet-os-mcp

A read-only MCP server of The Farm (`the-farm-v1.0-astras-pet-os-mcp-v1.0`): the agent in the seat reads the pets,
their intelligence levels, the open handoff cards and the rules from this repo's files. No write tools.

- Install and register on Windows: `mcp\register-astras-pet-os-mcp-20261026.ps1`
- Everything else (tools, the read-only rules, the client configs, tests): [docs/astras-pet-os-mcp-20261026.md](../docs/astras-pet-os-mcp-20261026.md)

By Astra.
