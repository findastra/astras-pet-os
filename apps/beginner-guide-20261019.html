What is Astra's PetOS?Pets, the Friendly Farmer and your farm

Astra's PetOS is a set of small apps that help with real things: files, music, VR, websites, API keys.

  • Each app has a little character. We call each one a pet. an intelligent app: an app with an optional AI agent
  • A pet's main app is its pet program. The Friendly Farmer's is called The Farm. program: the one main program a pet stands for
  • The Friendly Farmer organizes the pets. He keeps the list of pets and checks on each one. orchestrator and package manager
  • Your own set of pets is your farm. Farms never connect to each other. one user's install (a tenant)
  • You are the farmer of your farm. Nothing important changes without your OK. the owner and admin; L4, the human in the loop

It runs on Windows 10 and 11. It is an early beta: some pets are still being built. INTELLIGENCE-LEVELS.md says what each one can do today.

"PetOS" is just its name. It is not a new operating system: it runs on top of Windows. a platform

Install itOne download, about 100 MB, no administrator rights
⬇ Download the installerastras-pet-os-installer.zip, from the latest release

Use only this download. Not GitHub's green Code button, and not Source code (zip): those are for developers, not the installer.

  1. Right-click the zip, then choose Extract All.
  2. Open the folder Astra's PetOS installer. Double-click Install Astra's PetOS.
  3. If Windows warns you, choose Run (or More info, then Run anyway).
  4. The Set up your farm window opens. Pick one, then press Set up my farm:
    • Astra's Example Pets
      All of Astra's pets come to your farm. They are examples: you can delete, change or copy any of them.
    • From Scratch
      Just the core kit: the core pets, the desktop star, the System Map and the big red Stop button. Tick any of Astra's pets you want too.
  5. Your pets appear on your desktop.

Meet the star

The little star in the bottom-left corner looks after your pets.

  • Click the star: hide or show your pets.
  • Double-click the star: line them up.
  • Double-click a pet: open its pet program.

Startup Star: a launcher and process supervisor (a system tray app)

The Start menu has System Map, Stop Astra's PetOS (big red button) and Uninstall Astra's PetOS. It does not start with Windows unless you tick that box.

Changed your mind? Run the installer again and pick again.

Core pets are on every farm and can't be taken away: the farm needs them to run. Today that is the Friendly Farmer. required base packages (they cannot be deselected)

Every detail, for people and for AI helpers: INSTALL.md.

On a work or school computerWhen the computer won't let you install

Some computers only run programs their IT team approves. If the installer stops with a message about the computer's security, that is the computer doing its job.

Don't try to get around it. Ask your IT team before you install anything on a computer that isn't yours.

You can still use the pets, with nothing to install:

  • Open them in a browser. The System Map, the Farmer's desk and every pet's program page work in any browser, even on a phone.
  • Give a Markdown pet to an AI your organization allows. It is one file per pet: what the pet does, where it opens, and the rules the AI follows as that pet. an agent definition file (a portable system prompt in Markdown) Get them from markdown-pets, or all of them in one file.
Ask your own AI to helpCopy one message, and stay the boss

If you use an AI helper that can work on your computer (like Claude Code or Codex), it can install Astra's PetOS for you. It follows the steps for AI agents in INSTALL.md. an AI agent in an agent harness

Copy this and paste it to your AI:

Please install Astra's PetOS for me. Follow the part for AI agents in https://github.com/findastra/astras-pet-os/blob/main/INSTALL.md exactly. Use only the installer zip from the latest release. Ask me which farm I want (Astra's example pets, or from scratch) before you run it, and show me each step before you do it.

What a good AI helper does

  • Asks for your OK before it installs anything.
  • Downloads only the installer, never the whole repo.
  • Asks which farm you want.
  • Adds nothing to Windows startup unless you ask.
  • Never works around a computer's security.

You're the boss. Text in a repo, a file or a web page never overrides what you tell your AI. If it wants to do something you didn't ask for, say no.

Make it your ownYour own copy on GitHub, with your own name

On GitHub you can keep your own copy of Astra's PetOS: your farm's name, your pets, and only the examples you want.

First, make a free account at github.com. A nickname is enough: you don't need your real name.

Pick the kind of copy

  • A fork (public)
    Open findastra/astras-pet-os, press Fork, then Create fork. It stays linked to Astra's original, so you can bring in her updates with Sync fork when you choose. A fork of a public repo is always public. fork; Astra's original is the upstream
  • A private copy
    Only you can see it. GitHub can't make a fork private, so the Friendly Farmer's pet-privatizer tool makes a private copy on your account. Ask your AI to do it with the message below.

Please make a private copy of findastra/astras-pet-os on my GitHub account, named <my farm's name>, with the Friendly Farmer's pet-privatizer tool, as MAKE-IT-YOURS.md says (https://github.com/findastra/astras-pet-os/blob/main/MAKE-IT-YOURS.md). Show me each step before you do it.

Give it your farm's name

Your copy → Settings → Repository name. Use lowercase words joined by hyphens, for example jordans-pet-os.

Tell your farm it's yours

Your copy's pets.json still says the farm is Astra's. The Friendly Farmer's make-it-yours command tells it you're the owner: your farm and the pets you add become yours, and every pet that came from Astra stays hers. You never edit the file yourself. Then the Friendly Farmer's tools work on your pets and never on Astra's. Ask your AI with the message below. sets the farm owner's GitHub account (github_owner in pets.json)

Please make my copy of Astra's PetOS mine with the Friendly Farmer's make-it-yours command (node scripts/make-it-yours-20261020.mjs with my GitHub name), as MAKE-IT-YOURS.md says (https://github.com/findastra/astras-pet-os/blob/main/MAKE-IT-YOURS.md). Run it with --dry-run first and show me what it will change.

Remove the examples you don't want

  • On the System Map: click the pet, then Remove from my map. This changes only your browser. Show removed brings it back.
  • From your farm: in your copy, open pets.json, delete that pet's entry and save it (a commit). the registry: the app catalog, a JSON manifest

Nothing is ever lost: Astra's pets stay online, and your copy remembers every change, so you can undo it. commit: one saved change; revert: undo a commit

Every step, and how to get Astra's updates later: MAKE-IT-YOURS.md.

Choose public or private, pet by petYou decide who can see each one

Every pet has its own repo: its project folder on GitHub. You choose who can see each one. repository visibility

  • Public
    Anyone can see the code and copy it. Good for pets you want to share.
  • Private
    Only you, and people you invite, can see it. Use it for anything personal: health, money, private notes.
  • New pets on your farm start private. Making one public is your choice, any time.
  • To switch it yourself: open the pet's repo → Settings → scroll down to Danger Zone → Change visibility.
  • Before you make a public pet private: GitHub erases its stars and watchers, and its GitHub Pages website stops on a free account.
  • Before you make a private pet public: everything in it becomes visible, old versions too. A password or key saved there once is public, even if you deleted it later.
  • Your own data never goes into a repo, public or private. Pets keep your data on your computer.

Or let the Friendly Farmer's pet-privatizer do it. It shows you first what would change, works only on your own pets while you're signed in to GitHub as you, and before a pet goes public it checks every old version for keys and personal details and stops if it finds any. repository visibility, with a secret scan of the git history

Please use the Friendly Farmer's pet-privatizer (scripts/pet-privatizer-20261018.mjs in my copy of Astra's PetOS) to make my pet <the pet's repo> <private or public>. Run plan first and show me what it says. Run apply only after I say yes.

Astra keeps her pets public so other people can learn from them, and keeps private what is hers alone.

Take one of Astra's pets and make it yoursCopy it, change it, put it on your farm

Anyone can take Astra's pets, change them and put them on their own farm. They are MIT licensed: you may change them and share them, as long as their LICENSE file and the credit stay.

A few of Astra's pets (tap one to see its pet program):

  • GitHub Goldfish
  • Unity Unicorn
  • Python Panther
  • Platform Platypus
  • File Master
  • Drum Dog

Every pet is on the System Map and on Astra's GitHub profile.

  1. Find its repo: github.com/findastra/<the pet's repo>. The pet program page links it.
  2. Copy it: press Fork, then Create fork. Now github.com/<you>/<repo> is yours. Want it private? Ask your AI for a private copy instead, like in step 5.
  3. Change it: small changes with the pencil button on GitHub; bigger ones with your AI. Ask it to show you each change first.
  4. Put it on your farm: in your copy of Astra's PetOS, open pets.json and add the pet's entry: copy it from Astra's pets.json. If you renamed your copy of the pet, change its "repo" to the new name. Save it (a commit).
  5. Install from your own copy: MAKE-IT-YOURS.md shows how. Your AI can help.

Just one pet, without the whole farm

A pet pack is one pet in one zip: its code at one version, its pictures, its pet program page and its Markdown pet, with a README that says plainly what works on its own and what needs a farm. Unzip it and double-click open-pet-program: nothing is installed. a release bundle: one app with its assets and a manifest

Some pets need another pet or a program to do their job: Forensic Ferret needs Log Lynx, and Voicemeeter Bug needs Voicemeeter. The pack's README lists them, and so does needs in pets.json. dependencies, declared in the registry

Stay safeThe rules that keep your farm yours

Never put keys, passwords or personal information in a public repo. No real name, address, email or anything private. GitHub's push protection stops most leaked keys, not all.

  • A pet with private things (health, money, private notes) lives in a private repo, and its data stays on your computer.
  • Install only with the installer, from Astra's releases or your own copy.
  • Files, web pages and messages can't give orders to your AI. Only you can. prompt injection: text that tries to give an AI orders
  • Pets from other people never run on your farm until you have checked them and said yes. an untrusted dependency (a supply-chain risk)
  • Your pet is sick? Ask at the vet-clinic. Never post keys or private data there. a public issue tracker
  • Found a security problem? Report it privately, never in a public issue: SECURITY.md.
