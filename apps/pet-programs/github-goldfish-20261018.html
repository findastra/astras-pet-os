                  More details

                  branch-sweeper (github-aquarium-v1.0-branch-sweeper-v1.0) sorts every branch on every repo the farm owner owns. Safe to delete: all its work is already on the main branch, or its pull request was merged and nothing was added after, so deleting it loses nothing. Ask Astra: it may hold the only copy of some work (closed without merging, more added after a merge, or old work with no pull request). Keep: first the branches on your keep list, each with your reason, then the main branch, publishing, release and protected branches, open pull requests, branches an open handoff card names, and anything worked on in the last week. Checking changes nothing: npm run branch-sweeper -- --plan in the hub folder. Deleting happens only from that plan, only the rows marked to delete, only with your OK (--apply <plan> --yes), and each branch goes into an undo log on this PC first, so --undo puts it back. A branch you decided to keep goes on the keep list (branch-sweeper-keep-20261117.json, next to the plans on this PC): it is never offered for deleting again, even after its repo is renamed, and --apply refuses it even in an older plan and does not run without the list. The lists name private repos, so they stay on this PC; anywhere else this tool shows made-up examples.
