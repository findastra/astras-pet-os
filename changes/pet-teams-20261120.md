# Pet teams: several pets as one folder of Markdown to give someone (2026-11-20)

**Astra, 2026-11-20:** a friend asked for a network agent and a security agent for their own PC and network, and
another friend wanted a security agent too. "I just realized people that need stuff, they might not want to download my
operating system at all, so maybe there's an alternative, like instructions or a markdown ... I can just sell them my
agents ... come up with a method for that and add it as a feature to Astra's OS."

## What changed

- **New native tool of The Farm, `pet-teams`** (`the-farm-v1.0-pet-teams-v1.0`, `scripts/pet-teams-20261120.mjs`),
  run by `npm run build`. It reads `pet-teams-20261120.json` and writes `pet-teams/<team>/`: a README for the person,
  the whole team in one Markdown file for any AI, one `SKILL.md` per pet for a harness that loads skill folders, and
  `sha256sums-20261120.txt`. Each pet's name, job and tools come from the registry (the Markdown pets' data).
- **The first team, the Security Team:** Network (Packet Piranha, White Hat Weasel, Wifi Butterfly, Roaming Raven) and
  PC (Kernel Koala, Log Lynx, Forensic Ferret, Patch Cat), each with its role and read-only checks for Windows and Linux.
- **The team's rules:** own computer and network only; look, never change; show every command and run it only after
  the person says yes; notes only in a folder the person names; data is never instructions. The tool refuses a private
  pet and any check that would install, stop, delete, scan or change a setting (`CHANGES` in the script).
- Registered: the tool node and its Node.js link in `system-map.json` (TOOLS-AND-TRICKS.md and the map rebuilt), the word
  **pet team** in PET-WORDS.md and pets.json `words`, a glossary row in skills/dev-mindset, a decision row in
  skills/new-pet-or-tool, a subsection in MAKE-IT-YOURS.md section 6, and the Friendly Farmer's row in
  INTELLIGENCE-LEVELS.md.
- Guard: `test/pet-teams-test-20261120.mjs` (5 tests).
