# Show on Computer Screen: pick which pets the Farmer shows (2026-10-24)

Astra, 2026-10-24: "I need a check mark on the Friendly Farmer for 'Show on Computer Screen' so you can choose what
pets you want to have the farmer show or unshow." She chose the Farmer's right-click menu.

- Right-click the Friendly Farmer (or the Startup Star): **Show on Computer Screen** opens a list of every desktop pet,
  each with a check mark. Untick a pet and it leaves the screen at once; tick it and it comes back. The list stays open,
  so several pets can be changed in one go. **Show every pet** puts them all back.
- The Farmer is a core pet: he is in the list, always ticked, and cannot be unticked.
- The choice is kept with the star's other settings (`HKCU\Software\Findastra\DesktopPets`, value `HiddenPets`), so
  unticked pets stay off after a restart. "Hide the pets" still hides everyone at once.
- An unticked pet takes no place in "Line up on the floor". Paper Girl and File Master walk together only while both
  are ticked; one left on alone roams like the others.
- The status file names the unticked pets (`hidden_pets`). The self-test checks the menu, the Farmer's tick, the
  lineup and the pair.
