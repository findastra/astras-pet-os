Astra, 2026-10-21: "We are not doing passports. We are doing pet IDs ... Passport Pelican is the reason we are not
reusing passport."

  (`scripts/pet-program-pages-20261018.mjs`, pages rebuilt by `npm run build`). PET-PROGRAM-FRAMEWORK.md (the L4 row and

  the vet-clinic public later is a one-word change there and the link comes back.
- `test/pet-program-pages-test-20261018.mjs` checks every page has a Pet ID, no page says "pet passport", and the vet
