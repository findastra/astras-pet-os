# GitHub Aquarium's five outstanding-items groups are tools (2026-10-29)

Astra, 2026-10-29: "Broken on main, waiting on you, waiting on a chat, closer keep, being checked or drafts. All of
those things are tools. So turn them into what is supposed to be look like a tool and put them in the right spot."

- broken-on-main, waiting-on-you, waiting-on-a-chat, close-or-keep and being-checked-or-drafts are now round tool
  boxes in GitHub Aquarium's L1 control panel, under Native tools (13 there now). Each has its lights left of its name
  and folds to its name, like Rift Rabbit's VRChat setups and the L4 tools.
- The separate `github-goldfish-outstanding-items-tool-panel` above the four levels is gone. The Goldfish's line about
  where the list came from, the Open the Pets Board button and More details sit with the five tools.
- Broken on main keeps its red and waiting on you its orange. outstanding-items still fills them on her PC only, and
  pages anywhere else show the made-up examples. The page script is unchanged.
- `toolBox()` takes a class now; GitHub Aquarium is no longer in `PET_PANELS`.
